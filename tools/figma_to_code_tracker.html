Figma → Code Interactive Tracker

Kiến trúc tổng quan: Một màn Figma = Một View sinh tự động

Màn panel e-ink 240 × 416 (1 bit). View được sinh tự động bằng script C từ Figma, có mã hash bảo vệ. File Scene viết tay điều khiển hành vi, điền struct dữ liệu và submit intent hiển thị.

Figma Frame → figma2ink.py → <view>.gen.c + <view>.gen.h → render_view.py (diff = 0) → Scene C
1
Thiết lập Figma chuẩn Pixel Art Figma Setup

Chuẩn bị frame và các thông số hiển thị trước khi vẽ để tránh lỗi nửa pixel và font không hỗ trợ.

Cỡ khác line height là đúng: một em của font sinh ra là 16 pixel font (units per em 1024). Không dùng Tiny5 của Google Fonts: Figma áp kerning và đặt baseline khác panel.

py tools/figma2ink/make_u8g2_ttf.py u8g2_font_6x10_tf --family "Fixed 6x10" -o "$env:TEMP\fixed-6x10.ttf" --install
py tools/figma2ink/make_u8g2_ttf.py components/core/ink_ui/fonts/ink_ui_font_tiny5_8.c --family "Tiny5 Ink" -o "$env:TEMP\tiny5-ink.ttf" --install
2
Quy ước đặt tên Layer dữ liệu động & Nhịp vẽ Layer Naming

Tên layer trên Figma quyết định trường struct C trong file .gen.h.

3
Chạy công cụ sinh View (figma2ink.py) Code Generation

Đọc Figma REST API, kiểm các luật ở tab 4 và tự sinh code C cùng hash bảo vệ. Có lỗi thì không ghi file.

4
Kiểm thử Visual trên PC (render_view.py) Host Renderer

Biên dịch view bằng gcc thật trên PC và so sánh từng pixel với ảnh xuất từ Figma.

5
Tích hợp vào Scene C Firmware Scene

Scene phụ trách hành vi, điều khiển canvas và intent hiển thị.

6
Build, nạp và kiểm trên panel Device

Máy ngủ sau 60 s không bấm nút; khi ngủ cổng USB biến mất. Bấm A hoặc B ngay trước khi nạp, hoặc vào download mode (giữ BOOT, bấm RESET).

Bộ tạo lệnh tự động (PowerShell Terminal ESP-IDF)

Dán link frame từ Figma để tự động trích xuất key, node-id và tạo lệnh sinh view chuẩn xác:

Câu lệnh thực thi

1. Thiết lập biến môi trường token (nếu chưa lưu vĩnh viễn):

$env:FIGMA_TOKEN="figd_..."

2. Chạy công cụ sinh View và lưu snapshot:

python tools/figma2ink.py "..." --app ... --save build-render/snap

3. Biên dịch Host Renderer và so khớp pixel:

python tools/render_view.py ... --compare build-render/snap/figma.png

4. Build và nạp (bấm A/B trên máy ngay trước khi nạp; đổi COM theo cổng "USB Serial Device"):

idf.py build

5. Chụp panel bằng camera (Iriun Webcam đang chạy):

py tools/vision_test/capture.py -o ... --json

Lệnh chạy trong terminal ESP-IDF: . C:\Espressif\tools\Microsoft.v6.1.PowerShell_profile.ps1. Riêng py (capture, cài font) dùng Python hệ thống có numpy và fontTools.

Luật kiểm của figma2ink.py (theo docs/design/figma-to-code.md)

Bất kỳ lỗi nào (Lỗi) sẽ chặn sinh file để bảo vệ màn panel e-ink không bị vẽ sai hoặc tràn bộ đệm:

Luật kiểm Mức Lý do & Cách xử lý
Cỡ frame 240 × 416 hoặc 416 × 240 Lỗi Kích thước panel chuẩn. Sai cỡ sẽ không thể render đúng.
Tên frame <app>_<màn> Lỗi Tránh trùng ký hiệu hàm toàn cục khi liên kết firmware.
Toạ độ / Cỡ layer không nguyên Lỗi Panel e-ink không vẽ được nửa pixel. Kiểm tra X, Y, W, H.
Text style nằm ngoài 5 font ui Lỗi Firmware chỉ nhúng 5 font: unifont_vi_16, fixed_10, tiny5_8/16/24. Layer bị tách khỏi style (đổi line height trên layer) vẫn nhận được nếu font và cỡ đúng bảng font ở bước 1.
Màu lạ, gradient, opacity < 100%, effect Lỗi Panel 1 bit chỉ hỗ trợ đen, trắng và xám dither phẳng.
Chữ màu xám Lỗi Chữ xám bị ngưỡng 50% làm nhoè nét. Text chỉ dùng đen hoặc trắng.
Stroke canh giữa / ngoài Lỗi Họa cụ ink_ui_stroke() chỉ hỗ trợ vẽ vào trong (Inside).
Text {tên} để Hug / Auto height Lỗi Cỡ chữ động không biết trước khi chạy. Đặt fixed box cho text.
Text căn dọc giữa / dưới, letter spacing khác 0, nhiều style trong một text Lỗi ink_ui_text_draw() vẽ từ mép trên, một font. Text cao đúng một dòng thì căn dọc nào cũng được.
Layer ?tên ẩn trong Auto Layout Lỗi Figma dồn layout khi ẩn nhưng view không dồn; sẽ lệch pixel mẫu.
Line nằm lệch nửa pixel Lỗi Dùng Rectangle cao hoặc rộng 1 px thay vì Line vector.
Kiểu layer ngoài bảng ánh xạ Lỗi Không dùng ảnh, video, Auto Layout wrap, stroke dày khác nhau theo cạnh, góc bo khác nhau.
Mép layer động không chia hết cho 8 px Cảnh báo Display căn changed window theo byte (8 pixel) để tối ưu refresh.
Fill xám có corner radius Cảnh báo Mẫu dither 4×4 Bayer bỏ qua bo góc.
Stroke, line màu xám Cảnh báo Thành đen hoặc trắng theo ngưỡng 50 %; chỉ fill mới dither.
