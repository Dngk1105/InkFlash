# Yêu cầu

InkFlash là máy học flashcard bỏ túi, màn e-ink, 2 nút bấm, pin dùng nhiều tuần.
Phần cứng: `docs/hardware/index.md`.

| Mã | Yêu cầu                                                                                                 |
| --- | --------------------------------------------------------------------------------------------------------- |
| F1  | Ôn thẻ hoàn toàn offline, lịch ôn theo FSRS                                                         |
| F2  | Tối ưu cao về pin và phân bổ tài nguyên                                                           |
| F3  | Có cơ chế ngủ, thức giấc chuyển về trạng thái trước đó                                      |
| F4  | Tất cả thao tác đều được thực hiện bởi hai nút bấm. Tích hợp IMU để thao tác nhanh hơn |
| F5  | Nạp deck từ máy tính, cloud, bluetooth/wifi                                                           |
| F6  | Phát âm thanh có trong thẻ                                                                            |
| F7  | Khả năng đồng bộ hóa cao, cross-platform                                                            |
| F8  | Nhận giọng nói trên máy; chấm phát âm và AI chạy trên server                                   |
| F9  | Chạy được nhiều app, không chỉ flashcard                                                           |
