# Code demo v0 (lưu trữ không sử dụng/tham khảo)

Thư mục này là code firmware của bản demo phần cứng (breadboard), lấy nguyên từ tag `demo-v0` (commit `2e03eaf`).

- **Không được build.** Đây không nằm trong project chính, CMake không quét tới.
- **Dùng để tham khảo** cách viết driver cũ (màn, nút, IMU, audio, nguồn). Driver mới được viết theo [components/drivers/README.md](../../components/drivers/README.md).
- Muốn chạy lại bản demo, checkout tag: `git checkout demo-v0`.
